# Настоящая песня и гибрид ACE-Step на RTX 3060

**Версия архитектуры:** две ИИ-модели вызываются по очереди. **CORE:** Ubuntu 24.04 `/1tbdisk/muzikfed`; **веб-пульт:** http://192.168.0.100:9095 по LAN/VPN.

Подробно: [DUAL_AI_ARCHITECTURE.md](DUAL_AI_ARCHITECTURE.md). Внешний движок ACE-Step **не устанавливается автоматически с обновлением GitHub** и до первой установки кнопки аудиогенерации не активны.

## Три кнопки

1. **«Создать партитуру MIDI / MusicXML»**: выбранный обычный композитор или отдельный Qwen-полифонист. Ноты, партии, MIDI, MusicXML. MIDI можно прослушать через контрольный FluidSynth, но это не окончательное звуковое мастеринг-качество.
2. **«Создать песню по промпту»**: текущие описание, стиль, темп, лад и русский текст **напрямую** передаются ACE-Step 1.5; **MIDI перед этим не создаётся**. Если текст не введён, ACE-Step LM получает описание для генерации своих стихов. При инструментальном составе получается инструментальная AI-композиция.
3. **«Гибрид: MIDI-аранжировка → нейросетевой WAV»**: сначала сочиняем партитуру, рендерим MIDI в опорный WAV, затем передаём его ACE-Step в режиме `cover`. Партитура и результат могут отличаться; в вокальном гибриде требуется **готовый текст** (вписанный или полученный через Ollama).

**Не гарантируется**, что ACE-Step точно исполнит все MIDI-ноты, создаст идеальную оперную дикцию, будет не хуже Suno или отдаст раздельные `vocals.wav` и `instrumental.wav`. Это проверяется на настоящем CORE после установки, не в GitHub Actions.

## Установка ACE-Step один раз на CORE .100

```bash
ssh user@192.168.0.100
cd /1tbdisk/muzikfed
bash scripts/update-core.sh    # git pull, зависимости, тесты и перезапуск веб-пульта
nvidia-smi
bash scripts/install-ace-step.sh
```

`install-ace-step.sh` клонирует [официальный ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) в `/1tbdisk/muzikfed/engines/ACE-Step-1.5`, синхронизирует отдельное окружение `uv`, создаёт пользовательский `pocket-orchestra-ace.service`. Файлы моделей и зависимости находятся на 2-ТБ диске, не в GitHub и не в основном Python-окружении. Понадобятся интернет и несколько гигабайт свободного места.

**Запускать вручную необязательно:** после установки веб-кнопка сама стартует ACE-Step при запросе. Модель слушает только `127.0.0.1:8001` и **останавливается после готового WAV**, чтобы освободить RTX для Qwen. Первый вызов может скачивать веса; если загрузка не успела закончиться, повтори попытку после проверки журнала.

```bash
journalctl --user -u pocket-orchestra-ace.service -n 80 --no-pager
nvidia-smi
curl http://127.0.0.1:8001/health
curl http://192.168.0.100:9095/api/vocal/status
curl http://192.168.0.100:9095/api/gpu/status
```

Для ручного включения, если отлаживаешь API:

```bash
bash scripts/start-ace-step.sh
```

Для ручного выключения и освобождения видеопамяти:

```bash
bash scripts/stop-ace-step.sh
```

Выключение через браузер основного Pocket Orchestra останавливает только `pocket-orchestra.service`, **не другую запущенную службу**. Скрипт `stop-ace-step.sh` работает независимо.

## Тест русского оперного вокала

1. Открой на Acer http://192.168.0.100:9095 и обнови страницу `Ctrl+F5`.
2. Выбери **«Только голос»**, стиль **«Опера»** и опиши конкретный сюжет — настроение, динамику, голос, форму. Добавь свой текст песни для контроля дикции либо оставь пустым, чтобы ACE-Step предложила оригинальные слова.
3. Нажми **«Создать песню с русским вокалом по промпту»**. Она отправляет запрос прямо в ACE-Step, без псевдо-MIDI.
4. Смотри GPU/VRAM в мониторе. После завершения слушай и скачай `neural_song.wav`.
5. Для **гибрида** введи слова, выбери «ИИ-полифонист Qwen» при наличии Ollama и нажми **«Гибрид: MIDI-аранжировка → нейросетевой WAV»**. Qwen пишет ноты, выгружается из VRAM, а ACE-Step перерабатывает MIDI-аудио.
6. Для проверки инструментальной музыки выбери «Только инструменты» и нажми кнопку AI-композиции.

ACE-Step официально поддерживает задачи `text2music` и `cover`, локальный REST API, `sample_query`, WAV и русский вокальный текст как параметр. Но качество русских слов на конкретной модели — эксперимент. [API](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/API.md), [Установка](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INSTALL.md), [GPU](https://ace-step.github.io/ACE-Step-1.5/en/GPU_COMPATIBILITY).

## Обновление из GitHub

```bash
cd /1tbdisk/muzikfed
git pull --ff-only origin main
bash scripts/install-core.sh
bash scripts/status-core.sh
```

Либо `cd /1tbdisk/muzikfed && bash scripts/update-core.sh`. Последний скрипт **уже содержит настоящий git pull и перезапуск веб-службы**. Это не обновляет сторонний ACE-Step автоматически.

Порт `9095` держи в доверенной LAN/VPN, порт `8001` только на localhost. SSL/WireGuard и узел .109 не требуются для локального рендера.
