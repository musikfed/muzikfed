# ACE-Step 1.5 на RTX 3060: настоящий русский вокал (необязательный движок)

**Статус:** в Pocket Orchestra добавлен **API-мост** к ACE-Step 1.5, а не сама модель. Для первого запуска нужно **один раз явно установить и запустить** внешний движок на CORE. До этого оркестровый композитор, MusicXML/MIDI и FluidSynth продолжают работать без изменений. Автоматически ничего большого не скачивается.

## Как это работает

- Python-композитор пишет ноты и MIDI на Xeon; `preview.wav` = FluidSynth, синтезаторный предварительный звук.
- В режиме SATB можно ввести текст песни или получить `lyrics.txt`. **Слова при этом НЕ звучат в preview.wav.**
- Если отдельно запустить локальную ACE-Step, появляется возможность нажать **«Создать нейропесню с русским голосом»**. Песня генерируется по тексту, теме и стилю на RTX (если CUDA настроена), отдельно от нот.
- Для «Только голос» даём запрос **a cappella**, для «Инструменты + хор» — запрос с симфоническим сопровождением. Это **пожелание модели, а не гарантия**, что она действительно удалит/отделит все инструменты.
- Стили: опера/ария, марш, лирика, народный, атмосферный, кино. **Качество русской дикции и оперной манеры нужно проверить на слух.**
- Результат сохранится как `/1tbdisk/muzikfed/outputs/<job-id>/neural_song.wav`; через браузер будет отдельный плеер и ссылка скачивания. **Файл НЕ обязан совпадать с MIDI-партитурой и не является отдельным вокальным стемом**; это независимая нейропесня.

## Системные требования

- Ubuntu 24.04 CORE `192.168.0.100`, RTX 3060 12GB, работающий `nvidia-smi`, свободный диск /1tbdisk (модели порядка 10GB или больше плюс кэш), интернет для первого скачивания.
- ACE-Step официально поддерживает Python 3.11–3.12, CUDA и локальный API. Для 12GB разумно сначала использовать обычную turbo-модель вместо XL. Если возникает OOM, останови конкурирующие модели в Ollama и проверь GPU memory. Не меняй NVIDIA-драйверы без диагностики.
- ACE-Step — отдельный проект и виртуальное окружение в `/1tbdisk/muzikfed/engines/ACE-Step-1.5`. Это папка в `.gitignore`; файлы не попадут в твой GitHub.
- Pocket Orchestra использует только **http://127.0.0.1:8001** для общения с моделью. Порт 8001 **не открывай наружу**. Внешний веб-пульт `9095` остаётся доступен по существующему VPN.

[Официальная инструкция ACE-Step](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INSTALL.md) и [контракт HTTP API](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/API.md).

## Установка отдельного GPU-движка (только если хочешь настоящее пение)

В SSH терминале CORE `user`:

```bash
cd /1tbdisk/muzikfed
bash scripts/update-core.sh
nvidia-smi
bash scripts/install-ace-step.sh
```

Скрипт проверяет GPU, клонирует официальный ACE-Step в `engines/`, запускает **отдельный uv sync** и создаёт пользовательский unit `pocket-orchestra-ace.service`, **но не запускает модель и не трогает запущенный Pocket Orchestra**. `uv sync` скачает Python-зависимости из интернета. Убедись, что есть свободное место, и прочитай лицензии сторонних моделей.

После установки отдельно запусти:

```bash
cd /1tbdisk/muzikfed
bash scripts/start-ace-step.sh
```

Первый запуск может скачивать веса моделей (несколько ГБ); следи по SSH:

```bash
journalctl --user -u pocket-orchestra-ace.service -f
nvidia-smi
curl http://127.0.0.1:8001/health
curl http://192.168.0.100:9095/api/vocal/status
```

Только после того как локальный API модели начнёт отвечать, кнопка в веб-пульте станет доступной — обнови страницу Acer **Ctrl+F5**.

## Первый тест русского оперного голоса

1. В браузере открой `http://192.168.0.100:9095`.
2. Выбери **«Только голос»**, стиль **«Оперная фразировка»**, введи оригинальные русские строки в поле «Текст песни» или оставь пустым для черновика. Настройки сохраняются между обновлениями страницы.
3. Нажми **«Сочинить и оркестровать»**. Это создаст нотный проект с `lyrics.txt`.
4. В карточке **«Настоящий вокал · ACE-Step 1.5»** нажми **«Создать нейропесню с русским голосом»**.
5. После завершения появится аудиоплеер и ссылка **`neural_song.wav`**. Пока задача идёт, можно наблюдать за **GPU % и VRAM** на том же экране.
6. Повтори со стилем **«Лирика»** или **«Народная мелодика»** и сравни **разборчивость русского текста**, вокал и наличие посторонних инструментов.

Если нейросеть недоступна, получишь честное сообщение «не подключено», без запуска тяжёлых моделей. Не пытайся «включить» её галочкой Ollama — это другой AI-сервис.

## Остановить ACE-Step и освободить RTX

```bash
cd /1tbdisk/muzikfed
bash scripts/stop-ace-step.sh
```

Основной Pocket Orchestra и его обычный `preview.wav` при этом продолжают работать.

Для повторного запуска:

```bash
bash scripts/start-ace-step.sh
```

Две службы **независимые**. Обычная кнопка выключения Pocket Orchestra выключает только `pocket-orchestra.service`, а не ACE-Step; при необходимости останови ACE отдельно.

## Обновить Pocket Orchestra из GitHub

```bash
cd /1tbdisk/muzikfed
bash scripts/update-core.sh
bash scripts/status-core.sh
```

Это обновит **наш проект**, но не будет переписывать или обновлять внешнюю модель в `engines/`.

## Ограничения текущего подключения

- Мост реализован и покрыт тестами **с имитацией API**, без модели и GPU в GitHub Actions. Работу ACE-Step на настоящем CORE надо проверять после установки, результаты нельзя гарантировать заранее.
- Запуск музыки требует уже созданный нотный проект с `lyrics.txt`; в инструментальном режиме отдельная нейропесня пока не используется.
- Сгенерированный аудиофайл **не синхронизирован нотка-в-нотку с MIDI**.
- Слова на MusicXML сопрано пока подписываются по слову, а не правильно по фонемам/слогам. Для точного нотного пения нужен OpenUtau/DiffSinger с русским голосовым банком.
- Отдельных `vocals.wav`/`instrumental.wav` и сведения их в `mix.wav` пока нет. [Issue #1](https://github.com/musikfed/muzikfed/issues/1) остаётся открытой до реальных аудио-испытаний.

Никогда не публикуй сервис ACE-Step на публичном IP. Не требуется создавать платные облачные API-ключи.
