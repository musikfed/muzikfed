# Pocket Orchestra: одна RTX 3060, два композитора, MP3 и MIDI

**Выбор пользователя:** никаких аудио-ИИ на Windows .103. **Все нейросети только на CORE .100**, RTX 3060 12 ГБ, Ubuntu 24.04, репозиторий `/1tbdisk/muzikfed`, браузер `http://192.168.0.100:9095` по LAN/WireGuard. Windows .103 может использоваться отдельно для ручной работы в MuseScore/Ardor, но не для запуска ИИ.

## Три разные задачи вместо смешивания моделей

| Кнопка | Движок | GPU | Что получаем |
| --- | --- | --- | --- |
| **Создать партитуру MIDI / MusicXML** | CPU правила **или** Qwen3:8b / Ollama (два независимых нотных голоса, гармония и мотив из промпта) | CPU: 0 VRAM; Qwen: временно использует RTX | Полный MIDI и MusicXML, отдельные партии, 25-секундный MP3-фрагмент FluidSynth при установленном FFmpeg |
| **Проверочный AI-эскиз — 20 секунд** | ACE-Step Turbo | RTX по требованию | 20-секундный MP3 для проверки голоса, жанра и дикции — **самостоятельная проба**, а не точная первая часть полной песни |
| **Создать полную песню / AI-инструментал** | ACE-Step Turbo | RTX по требованию | Окончательный MP3 1–10 минут (или длина MIDI) |
| **Гибрид MIDI → нейросетевой MP3** | Сначала MIDI/Qwen, потом ACE-Step cover по временно отрендеренному WAV | **Строго последовательно** | Полные нотные файлы плюс AI-MP3; нейросеть может изменить некоторые ноты |

### Использование VRAM

- Для **CPU MIDI** GPU не используется вовсе.
- Если выбираешь **ИИ-полифонист Qwen**, Pocket Orchestra резервирует RTX, останавливает ACE-Step, предлагает Qwen составить гармонию/главный мотив *и* нотные линии двух независимых голосов, оркеструет остальные партии в Python. В конце делает запрос на выгрузку модели Ollama и снимает блокировку VRAM.
- Если выбираешь **ACE-Step**, резервируется та же RTX, Ollama получает запрос выгрузки модели. ACE создаёт MP3 и выключается. Вторая GPU-задача ждёт окончания предыдущей: если нажать новую тяжёлую кнопку пока GPU занят, будет явное сообщение «RTX занята», **не тайная параллельная загрузка обеих моделей**.
- Переключатель «Подключить Ollama» отдельно просит план и для нотного SATB — при выборе Qwen-полифониста план уже запрашивается **автоматически**. Включать оба флажка не обязательно.

Это кооперативная блокировка **наших** приложений: она не блокирует отдельные программы стороннего пользователя на GPU.

## Как просить именно хорошую MIDI-музыку

Пиши промпт по последовательности: **жанр → состав и тембры → короткий мотив → развитие → кульминация → разрешение → запреты**. Настройки рядом задают тональность, лад, темп, длину в тактах, плотность и силу духовых.

### Пример 1. Dendy / 8-bit аркада

- Состав: **8-bit / Dendy**; стиль: **8-bit / Dendy**; темп 140–160 BPM, тональность C/G или A minor; 32–64 такта.
- Промпт:

> Оригинальная восьмибитная тема приключений. Главная мелодия — чёткий запоминающийся квадратный pulse lead; второй независимый игровой голос отвечает фразами, арпеджио бегут восьмыми, бас упругий. A: весёлая аркадная тема с небольшими прыжками. A′: вариация и секвенции. B: напряжённый минорный уровень. Кульминация и каденция, затем возвращение главного крючка. Без вокала, не копировать известные игры.

Результат: реальные `chip_lead`, `chip_counter`, `chip_arp`, `chip_bass` в MIDI, отдельные партии в MusicXML. **General MIDI-звуки приближают старые игровые тембры, но не являются аппаратной NES-эмуляцией.** Для точного 2A03 саунда позже потребуется отдельный синтезатор/саундфонт, не только Qwen.

### Пример 2. Современная электронная MIDI-композиция

- Состав **Synthwave**, стиль **Synthwave**, 100–120 BPM, 32–64 такта.
- Промпт:

> Ночной мокрый город, оригинальный синтвейв. Сильный ровный synth-bass, тёплые длинные аккорды pad, бегущие арпеджио и вокально-певучий синт-лид. A: ясная 4-тактовая запоминающаяся тема. A′: синкопа и ритмическая вариация. B: контрастный гармонический поворот и новая контрмелодия. В финале возвращение темы и тихая светлая кода. Никаких известных мелодий.

### Пример 3. Оркестр / музыкальная драматургия

- Состав **оркестр**, стиль **симфонический/кино**; выбрать **ИИ-полифонист Qwen**.
- Промпт:

> Тихое тревожное вступление на виолончелях и флейте. Через четыре такта ясная мелодическая тема у скрипок. Развить её через секвенции и противоположно движущийся бас; B — светлая мажорная тема, затем усиление меди и валторн к кульминации. Сохранить самостоятельность инструментов и вернуть знакомый мотив в тихой коде. Без бесконечного повторения четырёх нот.

**Реальные ограничения:** Qwen пишет гармонический план и два нотных голоса, но не 12 полностью независимых полифонических партий. Оставшиеся партии формируются по проверяемым правилам. Зелёные тесты проверяют диапазоны/структуру/экспорт, но **не доказывают художественное качество**.

## Как создать красивую русскую песню

1. Выбери «Только голос» или «Инструменты + вокал».
2. Выбери желаемый тембр: сопрано, меццо, тенор, баритон, бас или дуэт. Это подсказка для модели, **не гарантия**.
3. Введи оригинальные русские куплеты/припев или оставь пустым для текстовой генерации ACE-Step; укажи эмоциональный сюжет, развитие, естественные вдохи и чёткую дикцию.
4. Нажми **20-секундный эскиз MP3**. При удачном тембре нажми **полную песню MP3**, выбрав 1/3/5/8 минут. Полная песня — новая независимая генерация; она не обязана повторить эскиз.
5. Если хочешь влияние нотной композиции, запускай **Гибрид**: Qwen/CPU создаёт MIDI, он временно звучит через FluidSynth, затем ACE-Step перерабатывает его в MP3. *Это не точное исполнение MIDI со всеми нотами*.

## Установка и обновление из GitHub на CORE

```bash
ssh user@192.168.0.100
cd /1tbdisk/muzikfed
bash scripts/update-core.sh
sudo apt install -y fluidsynth fluid-soundfont-gm ffmpeg
curl -fsS http://192.168.0.100:9095/api/health
curl -fsS http://192.168.0.100:9095/api/gpu/status
ollama list
```

ACE-Step уже устанавливается отдельно; **не нужно повторно скачивать её веса** при обычном обновлении. Никакого `ufw allow 8001`: ACE-Step остаётся доступной только внутри CORE на `127.0.0.1:8001`. Не открывай незащищённый веб-порт `9095` публично.

Обнови страницу на Acer через **Ctrl+F5**. Начни тесты с 32 тактов Dendy MIDI, затем Qwen-полифонию на 16 тактах, 20-секундный нейровокальный эскиз и 3–5-минутный MP3. Проверяй качество слухом и сравнивай разные промпты.
