# MP3 вместо WAV и длинные композиции на RTX 3060

## Что было и что стало

Раньше Pocket Orchestra определял длительность песни из 16 тактов 4/4 при 94 BPM: `16 × 4 × 60 / 94 ≈ 41` сек. Размер WAV не был причиной короткой композиции.

Теперь **отдельный выбор длительности ACE-Step**: как в MIDI, 1, 2, 3, **5 (по умолчанию)**, 8 или 10 минут. Длительность MP3 **не зависит** от поля «Такты 4/4». Модель ACE-Step получает `audio_duration` в секундах.

- **Нейропесня**: API ACE-Step напрямую генерирует **MP3**. Он скачивается потоково в `neural_song.mp3`, **WAV нейропесни не создаётся и не хранится**.
- **Партитура MIDI**: сохраняются `score.mid` и `score.musicxml`; при выбранном предпрослушивании FluidSynth создаёт временный WAV, FFmpeg переводит его в `preview.mp3`, после чего временный WAV удаляется.
- **Гибрид MIDI + ACE-Step**: MIDI-аранжировка автоматически удлиняется до выбранной длительности, формируется временный WAV-ориентир для функции `cover`; он удаляется **после успешного получения** `neural_song.mp3`. Ноты (MIDI/MusicXML) остаются. При сбое задач временный файл может сохраниться для диагностики.
- **Старые WAV** из прошлых запусков специально не удаляются, чтобы не потерять результаты, но новые AI-композиции используют MP3.

Для MP3-предпрослушивания MIDI на CORE нужен бесплатный FFmpeg:

```bash
sudo apt update
sudo apt install -y ffmpeg
```

ACE-Step MP3 формирует самостоятельно — FFmpeg для **нового нейросетевого MP3 не нужен**.

## Размер аудио и время генерации

Расчёт *размера файла* зависит от реального MP3-битрейта модели: 192 кбит/с ≈ 1.44 МБ/мин, 256 кбит/с ≈ 1.92 МБ/мин (десятичные МБ). При 256 кбит/с:

| Длительность | MP3, примерно | PCM WAV 48k/16-bit/stereo, примерно |
| --- | ---: | ---: |
| 1 мин | 1.9 МБ | 11.5 МБ |
| 3 мин | 5.8 МБ | 34.6 МБ |
| 5 мин | 9.6 МБ | 57.6 МБ |
| 8 мин | 15.4 МБ | 92.2 МБ |
| 10 мин | 19.2 МБ | 115.2 МБ |

**Не путай размер MP3 со скоростью генерации:** сжатие уменьшает файл, но почти не ускоряет сам нейросинтез. На RTX 3060 12GB время одного 5-минутного запроса не измерено в реальной системе. Оно зависит от `thinking`, offload в RAM, модели и длины текста. Честное число можно получить только измерив одно выполнение на CORE.

По [официальной таблице ACE-Step](https://ace-step.github.io/ACE-Step-1.5/en/GPU_COMPATIBILITY) для 8–12GB заявлено: **8 минут с языковой моделью и 10 минут без неё**. На 10 мин наш запрос ставит `thinking=false`; для вокала потребуется заранее введённый текст. На 5 и 8 минут может работать `thinking=true`. Это **лимиты настроек, а не гарантия** качества или беспроблемной работы на RTX 3060.

Для длинного гибрида MIDI должно иметь сравнимую длительность — например, 5 минут при 94 BPM требуют около **116–120 тактов**, а не 16. Веб-пульт вычисляет нужные такты по темпу; код поддерживает до 512.

## Как установить обновление из GitHub

```bash
ssh user@192.168.0.100
cd /1tbdisk/muzikfed
bash scripts/update-core.sh
sudo apt install -y ffmpeg  # только для MP3-предпрослушивания MIDI
```

Не нужно заново скачивать модель ACE-Step: её прежняя папка и веса сохраняются. Чтобы обновить время ограничения уже установленной пользовательской службы ACE-Step, **сначала останови её** (когда нет выполняющейся песни):

```bash
bash scripts/stop-ace-step.sh
bash scripts/install-ace-step.sh --skip-download
bash scripts/check-ace-step.sh
```

Установщик не меняет/перезаписывает чужой Git checkout ACE-Step, проверяет драйвер, CUDA, зависимости и обновляет только user systemd-unit; `--skip-download` не качает заново многогигабайтные модели. Если на CORE нет FFmpeg, нейропесни MP3 всё равно будут создаваться; MIDI-предпрослушивание будет содержать предупреждение.

Потом браузер Acer: **http://192.168.0.100:9095/** → **Ctrl+F5**. Выбери 3 минуты для первой длинной проверки, затем 5, 8 и 10. Сравни прослушивание: длительные треки могут повторяться или терять форму; **качество не следует из зеленых тестов**.

## GRAPHICS .103 и Radeon RX 7600 XT

[Проверка официальной совместимости Windows ROCm без установки](GRAPHICS_AMD_EXPERIMENT.md). Пока GTX/CUDA .100 остаётся проверенным вычислителем, Windows .103 — MuseScore/MuseSounds/Ardor. У AMD Radeon 16GB памяти, но RX 7600 XT (gfx1102) не подтверждена официальной таблицей ROCm 7.2.1 Windows. Возможность переноса ещё нужно доказать запуском PyTorch GPU и ACE-Step на .103.
