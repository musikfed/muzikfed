# Три режима Pocket Orchestra: первая композиция после обновления

Веб-интерфейс CORE: **http://192.168.0.100:9095**  
Репозиторий и результаты: **/1tbdisk/muzikfed**, **/1tbdisk/muzikfed/outputs/**.

Внимание: v0.1 **не умеет петь осмысленный русский текст**. Пункты «только голос» и «голос + оркестр» сейчас доступны **только как нотный макет хора SATB на гласных Ahh/Ooh/Mmm**. Это четыре хоровые партии, а **не одиночный певец**, не нейросинтез вокала и не отдельный голосовой WAV-стем. В первой музыкальной пробе важно проверить эти ограничения, не скрывая их.

## 0. Обновляем CORE, не создавая музыку

В SSH-терминале Ubuntu .100:

```bash
cd /1tbdisk/muzikfed
bash scripts/update-core.sh
bash scripts/check-core.sh
```

Скрипт обновления загрузит коммиты из GitHub в `/1tbdisk/muzikfed`, повторит unit-тесты и перезапустит пользовательский сервис. Если Git видит локальные незакоммиченные изменения, он остановится вместо перезаписи.

Проверка на самом CORE:

```bash
curl -fsS http://192.168.0.100:9095/api/health
```

Затем открой веб-пульт с Acer через VPN и **обнови страницу с отключением кэша (Ctrl+F5)**. Над полем названия появится **«01a · Режим создания»**.

## 1. Только инструменты — первый запуск

1. Выбери режим **«Только инструменты»**.
2. В поле **Состав** выбери **«Симфонический оркестр»** (12 партий). Альтернатива: струнный квартет (4 партии).
3. Для контролируемого примера оставь `D minor`, `16` тактов, `94 BPM`, `seed=42`, выключенную Ollama.
4. Включи «Создать черновой WAV» и нажми «Сочинить и оркестровать».
5. Проверь MusicXML, MIDI, JSON, WAV, список из 12 партий. Хоровых партий не должно быть.

## 2. Только голос — текущая тестовая замена

1. Выбери **«Только голос — сейчас нотный хор SATB без слов»**.
2. Поле **Состав** автоматически установит `choir` (четыре голоса SATB).
3. Выбери гласную `Ahh`, `Ooh` либо `Mmm`, выстави вступление с самого начала и нажми генерацию.
4. Проверь `score.musicxml`, `score.mid`, `choir.musicxml`, `choir.mid`.
5. Если включён черновой WAV, FluidSynth озвучит хоровые MIDI-партии простым GM-тембром — это **не** запись человеческого голоса.

**Для реального русского солиста/дуэта нужно интегрировать вокальную модель, работу с текстом, ударениями и таймингом и проверить её на RTX 3060 12 ГБ. Этот этап не готов.**

## 3. Голос + оркестр / аранжировка — текущая тестовая замена

1. Выбери **«Инструменты + хор — пока без русского пения»**.
2. В поле **Состав** выбери «Оркестр + SATB» (16 партий) или «Квартет + SATB» (8 партий).
3. После генерации проверь общий `score.musicxml` и `score.mid`; в дополнение получишь раздельные `choir.*` и `orchestra.*` либо `quartet.*`.
4. Все MIDI/MusicXML части синхронизированы по темпу и тактам. Отдельных WAV-стемов пока нет; для качественного звука используй MuseScore/MuseSounds на GRAPHICS .103.

## 4. Прогон без музыкальной оценки

Перед первыми художественными пробами можно проверить все нотные варианты:

```bash
cd /1tbdisk/muzikfed
python3 scripts/smoke-core.py
```

Проверка создаёт тестовые 8-тактовые задания в `outputs/` и контролирует наличие файлов. Художественное качество не оценивает. Файл `docs/TEST_MODES.md` содержит более подробную проверку.

## Что запланировано для настоящего русского вокала

После подтверждения работы трёх сценариев нужно отдельно реализовать: солист на русском языке, разборчивая дикция и ударения, длительность нескольких минут, отдельные WAV-стемы `vocal.wav` и `instrumental.wav`, управление текстом куплета/припева, совместный микс и синхронизация с партитурой. Не путать уже работающий SATB с выполнением этой задачи.
