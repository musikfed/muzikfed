01 · Задание композитору

Промпт → партитура
Инструментальный режим: партитура, MIDI и черновой WAV. Без вокала.
Режим Ollama позволяет LLM предложить гармонию и мотив. Без Ollama работает автономный композитор с заданной музыкальной формой.
Структура: жанр → ведущие инструменты → характер темы → развитие A/B → кульминация → финал. Пример заменяет только название, описание, состав, стиль и темп; слова песни сохраняются.
Второй движок вызывает Qwen для нот и контрапункта, затем освобождает VRAM. Это экспериментальная двухголосная полифония, не доказанное качество Баха.
Проверяем локальную Ollama и модель qwen3:8b…
Стиль влияет на мелодию и оркестровку. Для настоящих 8-bit MIDI-партий выбери состав «8-bit / Dendy». Вокал создаётся отдельной кнопкой.
Подсказка для нейросети, а не гарантированный выбор тембра; MIDI-хор по-прежнему не произносит слова.
Если вписаны стихи, они сохраняются в lyrics.txt и MusicXML. Если текст пуст, нейросеть ACE-Step сочинит слова из описания при запуске аудио; нотный WAV слов не произносит.

Воспроизведение WAV пока НЕ произносит текст; для настоящего русского вокала нужна отдельная модель.


MusicXML открой на Windows .103 в MuseScore Studio 4 с MuseSounds Core. Там же экспортируй качественный WAV. Быстрый WAV здесь — только черновой. Черновой WAV FluidSynth не произносит русский текст. Для настоящего вокала подключается отдельная ACE-Step; слова доступны в lyrics.txt.




ИИ-песни и гибрид · RTX 3060
Проверка модели...


Обе кнопки используют текущий промпт, стиль, темп и слова. Не случайные шаблоны: ACE-Step получает полный запрос. Модель включается только по требованию и после окончания освобождает RTX.





Длительность AI-аудио не зависит от тактов MIDI. Для гибрида число тактов увеличится автоматически. На 12 ГБ 8 мин — предел с LM; 10 мин — без неё. Объём MP3 примерно 2 МБ/мин.



Проверка тембра, жанра и русского произношения. Это отдельная генерация, не первые 20 секунд будущего трека. Для эскиза RTX используется отдельно от Qwen.




Первая кнопка — самостоятельный аудиогенератор, без обязательного предварительного MIDI. Вторая — сначала нотная партитура, затем ACE-Step cover. Результат cover может менять исходные ноты.


Для нейропесен нужно один раз установить ACE-Step на CORE; далее она будет запускаться по нажатию кнопки.
