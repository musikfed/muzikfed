Управление CORE .100

Служба systemd

Завершить работу Pocket Orchestra и отключить его автозапуск. Другие сервисы Ubuntu, VPN и программы не затрагиваются. Сохранённые файлы остаются на диске.

Показывается на сервере: cd /1tbdisk/muzikfed && bash scripts/show-control-token.sh. Никому не отправляй этот код.

После остановки эта страница больше не отвечает. Чтобы включить снова, зайди на CORE по SSH и выполни: bash /1tbdisk/muzikfed/scripts/start-core.sh. Проверка: bash scripts/status-core.sh.
